# 《山河武俠》網頁演示

這是《山河武俠》第一期可在手機瀏覽器遊玩的公開演示。關卡為第 15 章「青禾渡・鏢船夜盜」。

用手機直向打開本站即可遊玩：操作未具名瘦高鏢師，對上兩名外地夜盜。也可按「自動演示」看完整場戰鬥。岸上的阿禾只是旁觀，本關不上場。

戰鬥在瀏覽器裡的 Web Worker 中，由自架的 Pyodide 執行既有 Python 引擎；畫面只呈現戰鬥事件，不在前端重算傷害。美術目前是占位剪影與文字。

世界觀只使用正文公開資料第 1–240 章。招式套名「一腳一撥一甩」為遊戲原創。

若要在本機開啟，於本目錄執行 `python3 -m http.server 8765`，然後用瀏覽器打開 http://127.0.0.1:8765/ 。
