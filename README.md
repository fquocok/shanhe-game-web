# 《山河武俠》網頁演示

這是《山河武俠》可在手機瀏覽器遊玩的公開演示，風格為「江霧紙本」。打開後會先到青禾渡區域圖（第 3 期）：從阿禾的茅棚出發，跟著任務「那一夜」與「今天的竹牌」走過第 15 章那一夜到第二天一早；先點一個地點選中，再點一次才走過去。夜裡只開往渡口的那條路。路上可能遇到〔遊戲原創〕的小事「霧裡的狗」，畫面右下角會顯示探索種子，回報時請附上。原本的關卡列表收在「關卡回顧」。關卡中可進入第 15 章「青禾渡・鏢船夜盜」、回家路上的教學關「學那一腳」，以及第 2 期三個小關：第一篇的門檻、胡三的「輕功」、鹿鳴居廊下抬槓。其餘關卡顯示「未開放」。戰鬥可切換手動或自動出手。

在鏢船關中，操作未具名瘦高鏢師，對上兩名外地夜盜。也可按「自動演示」看完整場戰鬥。打完後可回區域圖。雙方都在鏢船船尾甲板上：鏢師守在近處甲板，夜盜從船尾舷緣爬上來。阿禾躲在老艄公的草棚後頭偷看，本關不上場。

本站可安裝到手機主畫面，作為獨立的測試入口（直向、獨立視窗）。在 Safari 用「加入主畫面」，或在 Chrome 用「安裝應用程式」。安裝後不必重裝即可收到更新：開啟時會優先下載最新的頁面與引擎；若已開著舊版，畫面會出現「有新版本」。

出手、受創、躲過與格擋會帶立繪全身位移，並與朱砂傷害數字、「格／空」印同一拍。若想看招式骨架，可按「墨線」。點選目標為整個人身，選取後再點一次（或按「出手」）才出招。

戰鬥在瀏覽器裡的 Web Worker 中，由自架的 Pyodide 執行既有 Python 引擎；畫面只呈現戰鬥事件，不在前端重算傷害。字型為自架的霞鶩文楷 TC 與 Noto Serif TC 子集。

世界觀只使用正文公開資料第 1–240 章。招式套名「一腳一撥一甩」為〔遊戲原創〕。

線上地址：https://fquocok.github.io/shanhe-game-web/

若要在本機開啟，於本目錄執行 `python3 -m http.server 8765`，然後用瀏覽器打開 http://127.0.0.1:8765/ 。
